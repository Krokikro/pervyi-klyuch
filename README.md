# «Первый ключ» — сайт услуги «аренда автомобиля с правом выкупа»

Статический сайт из четырёх страниц. Никаких сборщиков, зависимостей и интернета:
шрифт, картинки, стили и скрипты лежат внутри папки, поэтому сайт полностью работает
в локальной сети и офлайн.

---

## Как открыть

**Просто посмотреть на своём компьютере** — двойной клик по `index.html`.

**Открыть с других устройств в локальной сети** — запустите из папки сайта:

```bash
python3 -m http.server 8080        # macOS / Linux
py -m http.server 8080             # Windows
```

Дальше на любом устройстве в той же сети откройте `http://<IP-компьютера>:8080`
(IP смотрится через `ipconfig` в Windows или `ifconfig | grep inet` в macOS/Linux).

Вариант без Python — `npx serve .` или любой другой статический сервер.

## Структура

```
index.html          Главная
o-nas.html          О компании
uslugi.html         Услуги
kontakty.html       Контакты
robots.txt          Правила для поисковых роботов
sitemap.xml         Карта сайта
assets/
  css/style.css     Все стили и анимации
  js/main.js        Калькулятор, формы, меню, анимации появления
  fonts/            Inter (кириллица + латиница), self-hosted
  img/
    favicon.svg
    og.png          Картинка для превью в мессенджерах и соцсетях
    reviews/        Фотографии к отзывам (1–11)
    cut/            Вырезки без фона (webp с альфой) — люди и машины
                    как элементы оформления. Разрешение примерно
                    вдвое больше, чем блок на экране, чтобы на
                    ретине не мылилось. Все девять файлов вместе
                    весят около 700 КБ
```

Движение на сайте держится не на анимированных картинках, а на прокрутке:
первый экран «залипает», следующие блоки наползают на него сверху со
скруглением и тенью, машина за девушкой едет с другой скоростью.
Всё это — CSS scroll-driven animations там, где браузер их умеет,
и лёгкий запасной вариант на `requestAnimationFrame` там, где нет.
При `prefers-reduced-motion: reduce` движение выключается целиком.

## Что заменить перед публикацией

### 1. Контакты

Все контакты — заглушки. Меняются поиском по всем четырём HTML-файлам:

| Что | Найти | Где встречается |
|---|---|---|
| Телефон (ссылка) | `+74951234567` | `tel:`, `wa.me` |
| Телефон (текст) | `+7 (495) 123-45-67` | шапка, подвал, контакты, CTA |
| Почта | `info@pervyi-klyuch.ru` | подвал, контакты, JSON-LD |
| Telegram | `https://t.me/pervyiklyuch` | шапка, подвал, контакты, плавающая кнопка |
| WhatsApp | `https://wa.me/74951234567` | там же |
| Адрес | `ул. Бутырская, 62` и `127015` | подвал, контакты, JSON-LD |
| Домен | `pervyi-klyuch.ru` | canonical, Open Graph, JSON-LD, `robots.txt`, `sitemap.xml` |
| Название | `Первый ключ` | везде |

В macOS/Linux одной командой:

```bash
grep -rl '74951234567' . --include='*.html' --include='*.xml' --include='*.txt' \
  | xargs sed -i '' 's/74951234567/ВАШНОМЕР/g'
```

### 2. Отзывы — обязательно заменить

Одиннадцать отзывов на главной и фотографии в `assets/img/reviews/` —
**демонстрационные, написаны и сгенерированы для показа вёрстки**. Публиковать их
как настоящие нельзя: это подпадает под ФЗ «О рекламе» и «О защите прав
потребителей», а Яндекс и Google понижают сайты за поддельные отзывы. Блок помечен
комментарием в `index.html` — найдите `================= ОТЗЫВЫ`.

По этой же причине в разметке **намеренно нет** `Review` и `AggregateRating`.
Когда появятся настоящие отзывы с согласием клиентов — микроразметку можно включить,
и тогда в выдаче появятся звёздочки.

Под сеткой отзывов стоит форма «Оставить свой отзыв» с кнопкой «Отправить
на модерацию». Сейчас она, как и остальные формы, ничего никуда не шлёт —
показывает подтверждение и всё. Отправку подключать в `assets/js/main.js`,
блок «Формы»: там один обработчик на все формы, различать их можно по
атрибуту `data-form` (`review`, `lead-main`, `lead-modal`, `contact`,
`lead-biz`). Отзыв должен уходить не сразу в публикацию, а на проверку —
иначе форма превратится в дыру для спама.

### 3. Реквизиты и политика конфиденциальности

На странице контактов (`kontakty.html`, блок `#politika`) стоят образцы. Реквизиты
подставьте настоящие, а политику конфиденциальности разместите полностью — этого
требует 152-ФЗ, без неё нельзя собирать заявки.

### 4. Обработка форм

Формы сейчас только валидируются на клиенте и показывают экран «отправлено».
Отправку подключите в `assets/js/main.js`, блок `Формы` — там оставлен комментарий
с местом под `fetch()`. Подойдёт что угодно: свой скрипт, Formspree, Telegram-бот,
вебхук в amoCRM или Битрикс24.

### 5. Карта

На странице контактов стоит стилизованная схема (обычный SVG, работает офлайн) и
кнопка «Открыть в Яндекс.Картах». Если нужна настоящая карта — вставьте виджет
Яндекс.Карт на место `<div class="map">`. Учтите, что виджет требует интернета и
заметно тормозит загрузку страницы, поэтому его лучше подгружать по клику.

## Калькулятор

Формула лежит в `assets/js/main.js`, функция `recalc()`:

```
взнос          = стоимость × процент взноса
сумма договора = (стоимость − взнос) × (1 + наценка)
наценка        = 50% за первый год, +25% за каждый следующий (макс. 150% на 5 лет)
выкупной       = сумма договора × 5%
платёж в месяц = (сумма договора − выкупной) / число месяцев
```

Клиенту показываются только платёж, взнос и срок — как вы и просили. Наценка и
итоговая сумма на сайте не выводятся.

Отдельно стоит подумать вот о чём: закон о защите прав потребителей требует
доводить до покупателя полную стоимость до подписания договора, и практика
показывает, что честно названная сумма на сайте отсеивает не тех, кто и так не
дошёл бы до сделки. Если решите показывать — в блоке `.calc__rows` достаточно
добавить две строки, все переменные в скрипте уже посчитаны.

## Что уже сделано под SEO

- Уникальные `title` (55–62 символа) и `description` (136–146 символов) на каждой странице
- По одному `H1` на страницу, вложенность `H2`/`H3` без пропусков
- Тексты не дублируются между разделами: главная — про условия, «О нас» — про компанию
  и юридическую механику, «Услуги» — про подбор, проверку и договор, «Контакты» —
  про связь, партнёрство и инвестиции
- Микроразметка Schema.org: `AutoDealer`, `WebSite`, `Service` (три услуги),
  `FAQPage` (три разных набора вопросов), `BreadcrumbList`, `ContactPage`, `AboutPage`
- Open Graph для превью в мессенджерах, `canonical`, `robots.txt` с `Clean-param`
  для Яндекса, `sitemap.xml`
- Объём текста: главная ~2000 слов, «О нас» ~1240, «Услуги» ~1230, «Контакты» ~715
- Скорость: ни одного внешнего запроса, шрифт 67 КБ, все картинки в WebP,
  общий вес страницы меньше 250 КБ

### Что стоит сделать дальше

1. Купить домен и поставить HTTPS — без него в топ не выйти
2. Подключить Яндекс.Вебмастер и Google Search Console, отправить `sitemap.xml`
3. Завести Яндекс.Бизнес (карточку организации) — для локальных запросов это
   даёт больше, чем любая правка на сайте
4. Поставить Яндекс.Метрику с вебвизором и целями на отправку форм
5. Через месяц-два добавить блог или раздел «частые ситуации» — под низкочастотные
   запросы вида «дадут ли машину с просрочкой по кредиту»
6. Собрать настоящие отзывы и включить микроразметку `Review`

## Проверено

- Вёрстка на ширинах 320, 375, 768, 1280, 1920, 2560 и 3840 px — горизонтальной
  прокрутки нет нигде, ничего не обрезается
- Все внутренние ссылки и якоря ведут на существующие страницы и блоки
- Калькулятор сверен с формулой на пяти наборах значений
- Формы: валидация, маска телефона, экран успеха
- Мобильное меню, аккордеон вопросов, анимации появления
- Ошибок в консоли нет, битых запросов нет
- Анимации только на `transform` и `opacity` (не вызывают перерисовку страницы),
  есть поддержка `prefers-reduced-motion` для тех, у кого в системе отключены анимации
